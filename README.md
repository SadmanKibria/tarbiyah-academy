# Tarbiyah Academy

A modern, mobile-first website for Tarbiyah Academy in Ilford. The site presents the academy's Qur'an, Hifz, Islamic Studies and diploma programmes, with a clear enrolment journey for parents and students.

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Custom responsive CSS

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production

```bash
npm run build
npm start
```

The site is deployed automatically from the `main` branch.
